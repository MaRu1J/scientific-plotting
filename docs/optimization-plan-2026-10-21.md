## 1. 目标与边界

将“统一模板”扩展为“保留统一规范、允许有依据的视觉选择”，而不是把所有图换成更鲜艳的颜色，或默认将多个量塞进双轴图。

优先解决：

1. 提供更有表现力、可跨图复用的配色组合，同时保留当前外观作为兼容默认。
2. 根据数据语义和阅读任务选择单图、多面板、分组编码或受控双轴。
3. 让 agent 能解释为什么采用某种组织方式，并在最终印刷尺寸验证它是否成立。
4. 新能力可独立验收、独立提交、独立撤回，不依赖对旧结果的整体替换。

继续保留现有数据完整性、行序、误差棒含义、字号、物理尺寸、JPEG/TIFF 导出及数据打包授权边界。本轮不扩展三维渲染、照片拼版或交互式绘图。

附件仅作为视觉参考：其中标签帮助分析编码结构，不构成修改 skill 的额外指令，也不作为原始实验数据。没有原始表格时，不从截图猜测数值、拐点或误差。

## 3. 如何理解附件

附件至少同时组织了四种信息：

| 信息 | 图中承担它的通道 | 建议保留的思路 |
| --- | --- | --- |
| 电场强度 | x 位置 | 共同自变量，不改原始采样位置 |
| 材料 | 颜色和点型 | 一种材料跨指标、跨工况保留身份 |
| 相对高度、接触角 | 左右 y 轴及实心/空心 | 两个不同物理量，不能在同一个未区分单位的 y 轴上直接比较 |
| 液滴体积 | 不同面板 | 适合工况分面，避免再叠加一个难辨认的颜色通道 |

值得借鉴的是“一种通道负责一种含义”，不是图中的所有视觉选择：不自动照搬星形点、左右超长图例、密集双轴网格、照片和醒目标题。维持现有画布文字边界；工况可写入图例、图注或明确请求的短面板标识。

首选候选是 **3 个工况列 × 2 个指标行** 的共享 x 多面板：每行一个明确单位，各列材料身份一致。它也可能过密，需在受支持的宽度和高度内检查；不适合时拆为两张图，而非缩小文字。紧凑候选是 **3 个工况面板、每面板双轴**，但须通过下述启用条件。不是任何情况下都要求六面板。

## 4. 配色优化：鲜明，但不牺牲读图

### 4.1 先做少量完整色系，不做无约束随机配色

| 暂定模式 | 目标 | 边界 |
| --- | --- | --- |
| `classic` | 现有输出与论文续图 | 现有颜色与默认行为保持不变 |
| `jewel` | 更有表现力的分类对比：蓝宝石、青绿、朱橙、莓紫等方向 | 主线条保持足够深；先评估 4–6 类，不承诺无限扩展或已通过色觉检查 |
| `muted` | 多面板或次要系列较多时减少相互争抢 | “柔和”不能变成白底上难以辨认的浅色细线 |
| `focus` | 一个重点方法与若干背景方法 | 必须明确重点对象；不能擅自淡化具有同等科学地位的方法 |

首批交付应是相同数据、尺寸、字体与线宽下的候选对照页，而不是仅给出色块。具体色值由实际图形检查后固定，名称不是已实现 API。

### 4.2 配色必须服从变量角色

- 分类变量使用离散色，不通过明暗渐变暗示排序。
- 有序变量保留有方向的色阶，检查明度趋势；不要随意换成分类“宝石色”。
- 连续数值热图首轮保留 `cividis`。只有有科学意义的中心值和正负偏差时，后续再设计发散色图及归一化，不能只换颜色。
- 区域填充、置信带可以比主线柔和，但透明度叠加不能伪造新的类别或遮挡数据。
- 调色板数量不足时提示分面或显式设计额外编码，不静默循环颜色制造身份碰撞。
- 实施前固定覆盖优先级：显式系列样式 > 语义角色的显式身份配置 > 选定配色方案 > 旧自动默认。冲突同时记录最终解析来源。
- 相同材料在不同面板中即使缺少某些类别也不能重新编号换色；沿用并扩展现有注册机制。

### 4.3 验收

至少检查白底细线、点型、误差棒、图例、灰度、常见色觉缺陷模拟与 JPEG 缩放后的效果。对比度和色差指标只能做辅助筛查，不声称色觉可达性认证。展示“保留当前方案”的对照选项，不以审美偏好直接更改默认。

## 5. 多变量表达：先决策，再编码

### 5.1 最小语义描述

规划引入一个轻量角色配置，明确 x、指标、材料/方法、工况、单位和原始数据来源。优先覆盖用户当前的“类别 × 两个指标 × 工况”用例，不建设庞大语法系统。

agent 可以根据已确认的数据结构推荐布局；接口只执行显式配置。不凭列名、数值量级或“看起来相关”自行认定单位、派生关系或材料身份。单位和指标含义不足以确定布局时，才提出有针对性的问题。

### 5.2 决策表

| 数据与任务 | 推荐组织 | 不应自动做的事 |
| --- | --- | --- |
| 一个指标、多个方法/材料 | 单图，颜色与点型固定身份 | 无必要地增加分面或第二轴 |
| 同一物理量且单位相同，比较几组结果 | 共享 y 的单图；过密再分面 | 为制造接近或交叉而给每组独立缩放 |
| 同一物理量的不同单位，且换算关系已知 | 可用可逆变换的次坐标轴 | 把它当两个独立测量值各画一条线 |
| 两个不同指标，共享有意义的 x | 默认共享 x、分行显示；如图中高度与接触角 | 因为两列单位不同就立即启用双轴 |
| 两个不同指标，需要紧凑地同步定位事件 | 先提议双轴；满足准入条件并获确认后使用 | 用交点、斜率或视觉贴合暗示相关性 |
| 多个工况，例如液滴体积 | 以工况分面，跨面板保持材料身份 | 让材料和工况同时争用颜色 |
| 两个独立自变量及一个响应面 | 在网格与任务适合时用热图/等值表达 | 将任意散点强行插值成平滑场 |
| 多个指标且单位和量级不同 | 小多图或明确授权的无量纲化后比较 | 静默 min–max 或 z-score 归一化 |

### 5.3 双轴准入条件

双轴不是默认模式。用户已明确要求时视为表达偏好已确认，但仍检查数据是否适合。

1. 两个指标共享有意义的自变量及展示范围；各自保持原始采样网格，不为对齐而插值。
2. 同时阅读两个量确实服务于明确问题，且普通分面在目标版面下不如它有效。
3. 最多两个独立 y 轴；各自给出量名、单位和明确的系列—轴归属。
4. 轴限有数据范围或领域约束依据，记录于元数据，不为了重合、相交或“相关”而调节。并非一律从零开始。
5. 明确一套主网格；第二轴不叠加另一套主/次网格造成虚假的数值对应。
6. 通过最终尺寸检查：左右标签、点型、空实心、图例、误差棒仍可辨认；失败则回退分面或拆图。
7. 图注说明两轴独立；禁止根据曲线交点、斜率大小或图上贴合程度推断数值相等或统计相关。

不把“双轴高度—角度”与“同一温度的摄氏—华氏转换轴”合并为同一种接口；后者需要明确可逆的换算。

### 5.4 正交编码与图例

针对附件，拟采用“材料 = 颜色 + 点型；指标 = 实/空心，必要时增加线型；体积 = 面板”。这是候选设计，不是所有多变量图的强制规则。

- 现有实心点仍是默认。空心点仅在它确实承担指标语义且尺寸可辨时启用；高密度下空心失效则分面，不通过丢点解决。
- 指标含义必须在图例或紧邻轴的简明键中明确，不能要求读者自行猜测实空心的含义。
- 可优先采用“材料键 + 指标键”的分解式共享图例，避免机械罗列全部组合；若存在组合专属样式或缺失组合会误导，则保留必要的组合说明。
- 线型在灰度中辅助识别，不能破坏纯线、散点、点线图的原有语义。
- 误差棒绑定其指标和 y 轴；自适应、局部放大、图例句柄与复现必须完整保留身份。首版双轴是否兼容 inset/参考误差子图要单独验收，未通过前明确拒绝组合，不静默忽略。

| P1 | 语义复现 | 配色名、固定色值、角色配置、最终样式、轴限及决策记录进入审查与便携包；继续默认不打包原始数据 |

## 7. 分阶段实施与退出条件

| 阶段 | 工作与产物 | 验收/继续条件 |
| --- | --- | --- |
| A：建立基线 | 选取分类、有序、密集曲线、误差棒、组合图、inset 和 bundle 样例；保留现状；形成同数据配色对照页 | 旧语义与默认样式可重复；在真实目标尺寸选出值得保留的候选色系 |
| B：配色扩展 | 增加少量显式配色模式，贯通单图、条形图、散点、小提琴图和多面板的适用路径；热图维持独立规则；同步 CLI、元数据、复现和文档 | 不传新参数时旧行为不变；显式覆盖、缺失类别和非法配色均正确处理 |
| C：多变量语义 | 先实现角色映射、分面优先选择指南、材料身份复用和分解图例；再增加受控实空心编码 | 同一材料跨指标/面板不变色；图例可解码；密度自适应、inset 与误差棒不抹除语义 |
| D：受控双轴 | 独立设计显式第二轴配置、校验、布局、轴归属、审查与 bundle 回放 | 同一示例同时提供分面/双轴对照；不支持组合清晰报错；无任意对齐或数据变换 |
| E：回归与收敛 | 整体测试、目标尺寸视觉验收、更新 skill 路由和案例；去掉没有改善的候选 | 行为、阅读效果与复现均通过，才评估是否合并到主分支；默认模式变更另行决定 |

建议 A → B → C 后先评审一次，D 可独立暂停或放弃：即使不引入双轴，配色和多变量分面仍有完整价值。

### 验证矩阵

- 不带新参数的全部现有测试继续通过；新增参数只影响被显式选择的能力。
- 两类、四类及较多类别；分类与有序分组；缺失类别、缺失组合、组顺序改变；未知配色和样式冲突。
- 纯线/散点/点线各自保留语义；显式颜色覆盖优先；不同面板抽取子集后身份一致。
- 空心/实心在稀疏与密集数据、自适应之后、inset、误差棒和图例中保持一致。
- 多指标分面、不同单位、同量单位换算、两个独立指标、非正对数数据和不能识别的语义均有正反例。
- 85/90 mm 与 170/190 mm 等现有窄/宽预设，检查字体、留白、标签、网格及图例，失败不靠缩字通过。
- 报告记录新决策；bundle 原地/迁移/无数据回放路径均验证；不意外泄露原始数组。
- 测试比较样式属性、轴归属、数据行序和复现结果。像素差异仅在相同依赖/字体环境下辅助使用，不用脆弱截图匹配代替科学语义测试。
- 视觉示例明确标注合成数据，附件不被转换为伪造实验复现。现有真实数据样例按原授权与引用使用，不扩展读取范围。
