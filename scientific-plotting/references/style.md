# Scientific figure style contract

## Locked defaults

| Aspect | Rule |
| --- | --- |
| Canvas | White; standalone plots follow the reference image's roughly 4:3 canvas (1336 × 994 px): single 89 × 66 mm or double 183 × 136 mm. The tall/multipanel preset remains 183 × 180 mm. For line-like figures, leave visible margins around the axes (about 13.5% left, 9% right, 13% bottom, 5% top, expanding as needed for labels); do not stretch the canvas to fill it. |
| Font | Arial first; warn and use Liberation Sans if unavailable. Explicit Times New Roman requests warn and use Liberation Serif if unavailable. Check text layout after substitution. |
| Text sizes | At final output size, `single` uses 10 pt axis names, 8.5 pt tick labels and legend, 10.5 pt optional title. `double`/`multipanel` use 11 pt axis names, 9.5 pt tick labels and legend, 11.5 pt optional title. Colorbar tick labels follow tick size. Never shrink legend text to force it inside; try another position, then outside or ask for a larger preset. Keep the intended print width: scaling a double-width figure down to single-column width halves the apparent text size. Journal-specific requirements take precedence when provided. |
| Frame/ticks | All four spines and both-side tick marks; major and minor ticks directed inward. If a mark obscures boundary data, an explicit exception may move ticks outward. |
| Grid | Numeric axes have visible mid-gray solid major lines and lighter but legible dashed minor lines, behind the data. Gridlines within 4 pt of the frame are hidden so they cannot double the border; ticks remain visible. Bar and violin use the value axis only. Heatmap has no overlay grid. |
| Legend | Try non-overlapping locations inside first, with upper center first; vary the number of columns before moving outside the fixed canvas. Never shrink its font to make it fit. When a single-column plot needs an outside legend, warn that the plot area is reduced and suggest the double-width preset. |
| Color | Ordered numeric/datetime groups progress from a readable amber through yellow-green and green to deep blue-teal (early → late); a single series uses deep blue-teal. Favor clear contrast against white rather than fluorescent yellow. Unrelated methods use a separate restrained categorical set. Reuse semantic colors consistently and add marker shapes or line styles for grayscale readability; these custom colors are not claimed to have formal CVD certification. |
| Stroke and markers | For line and point-line plots, measure adjacent points *within each series* after layout, not nearest points across series. Sparse spacing uses 1.8 pt lines / 5 pt markers; ordinary spacing uses 1.45 pt / 3.5 pt; close spacing uses 1.35 pt / 3.5 pt filled markers, with 1.2 pt / 2.4 pt only for extreme within-series crowding. Plain lines have no markers. Scatter uses its own nearest-neighbor rule: 5.5 pt normally, at least 4.5 pt for dense points, with subtle transparency and distinct shapes for overlapping categories. Marker sizes are diameters in pt (scatter area is diameter squared). Optional explicit `--line-width` and `--marker-size` override automatic sizing for applicable kinds. |
| Output | PNG only when unspecified; SVG, PDF, TIFF, EPS only when explicitly selected. PNG/TIFF raster at 300 dpi by default (adjustable); vector text stays editable when the chosen font is available. Avoid alpha blending for EPS. |

For point-line plots, connect data points in source-row order *within each group* and show markers. Plain lines omit markers; scatterplots never connect them. Do not fit or smooth. A trend line, error bar, shaded uncertainty band, significance mark, or ratio must have an explicit data basis and definition. The template does not add any of these automatically. Do not interpret a color band as a confidence interval without a statistic supplied by the user.

The overall aspect ratio comes from one of three presets; long legends may use a larger preset rather than arbitrary resizing. Line-series overlap alone does not force thinner lines or smaller points; scatter overplotting uses moderate transparency without removing observations. These are presentation-only adjustments: never remove points or change their order. Axis labels should contain units when applicable; a title is optional and cannot replace the axis labels. For heatmaps, use a perceptually uniform scale, colorbar and readable category labels. Bar groups require pre-aggregated values, not silently summed repeated observations. Repeated long-form heatmap cells similarly require explicit aggregation.

The user's reference image is a *style example*, not a source of experimental data or permission to recreate its curves. "Origin-like" here describes the requested framed axes, typographic balance, breathing room, grid hierarchy and distinct plotted series, not a claim to reproduce a specific OriginLab graph template. If journal instructions conflict, apply them only to the requested figure and state what differs from this default.
