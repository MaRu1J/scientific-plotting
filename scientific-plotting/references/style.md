# Scientific figure style contract

## Locked defaults

| Aspect | Rule |
| --- | --- |
| Canvas | White; standalone plots follow the reference image's roughly 4:3 canvas (1336 × 994 px): single 89 × 66 mm or double 183 × 136 mm. The tall/multipanel preset remains 183 × 180 mm. For line-like figures, leave visible margins around the axes (about 13.5% left, 9% right, 13% bottom, 5% top, expanding as needed for labels); do not stretch the canvas to fill it. |
| Font | Arial first; warn and use Liberation Sans if unavailable. Explicit Times New Roman requests warn and use Liberation Serif if unavailable. Check text layout after substitution. |
| Text sizes | At final output size, `single` uses 10 pt axis names, 8.5 pt tick labels and legend, 10.5 pt optional title. `double`/`multipanel` use 11 pt axis names, 9.5 pt tick labels and legend, 11.5 pt optional title. Colorbar tick labels follow tick size. Never shrink legend text to force it inside; try another position, then outside or ask for a larger preset. Keep the intended print width: scaling a double-width figure down to single-column width halves the apparent text size. Journal-specific requirements take precedence when provided. |
| Frame/ticks | All four spines and both-side tick marks; major and minor ticks directed inward. If a mark obscures boundary data, an explicit exception may move ticks outward. |
| Grid | Numeric axes have visible mid-gray solid major lines and lighter but legible dashed minor lines, behind the data. Linear axes use AutoMinorLocator; log axes use base-10 LogLocator with decade majors and 2–9 minors (2/5 for crowded decades below 60 working pixels after layout), including residual plots spanning ten decades. Never use AutoMinorLocator on log axes. Gridlines within 4 pt of the frame are hidden so they cannot double the border; ticks remain visible. Bar and violin use the value axis only. Heatmap has no overlay grid. |
| Legend | Try non-overlapping locations inside first, with upper center first; vary the number of columns before moving outside the fixed canvas. Explicit `legend="outside"` skips inside trials. Try the right margin, then a measured top band for longer labels; refuse labels that cannot fit. Never shrink its font to make it fit. When a single-column plot needs an outside legend, warn that the plot area is reduced and suggest the double-width preset. |
| Color | Ordered numeric/datetime groups progress from a readable amber through yellow-green and green to deep blue-teal (early → late); a single series uses deep blue-teal. Favor clear contrast against white rather than fluorescent yellow. Unrelated methods use a separate restrained categorical set. Reuse semantic colors consistently and add marker shapes or line styles for grayscale readability; these custom colors are not claimed to have formal CVD certification. |
| Stroke and markers | For line and point-line plots, measure adjacent points *within each series* after layout, not nearest points across series. Sparse spacing uses 1.8 pt lines / 5 pt markers; ordinary spacing uses 1.45 pt / 3.5 pt; close spacing uses 1.35 pt / 3.5 pt filled markers, with 1.2 pt / 2.4 pt only for extreme within-series crowding. Plain lines have no markers. Scatter uses its own nearest-neighbor rule: 5.5 pt normally, at least 4.5 pt for dense points, with subtle transparency and distinct shapes for overlapping categories. Marker sizes are diameters in pt (scatter area is diameter squared). Optional explicit `--line-width` and `--marker-size` override automatic sizing for applicable kinds. |
| Output | PNG only when unspecified; SVG, PDF, TIFF, EPS only when explicitly selected. PNG/TIFF raster at 300 dpi by default (adjustable); vector text stays editable when the chosen font is available. Avoid alpha blending for EPS. |

For point-line plots, connect data points in source-row order *within each group* and show markers. Plain lines omit markers; scatterplots never connect them. Do not fit or smooth. A trend line, error bar, shaded uncertainty band, significance mark, or ratio must have an explicit data basis and definition. The template does not add any of these automatically. Do not interpret a color band as a confidence interval without a statistic supplied by the user.

The overall aspect ratio comes from one of three presets; long legends may use a larger preset rather than arbitrary resizing. Line-series overlap alone does not force thinner lines or smaller points; scatter overplotting uses moderate transparency without removing observations. These are presentation-only adjustments: never remove points or change their order. Axis labels should contain units when applicable; a title is optional and cannot replace the axis labels. For heatmaps, use a perceptually uniform scale, colorbar and readable category labels. Bar groups require pre-aggregated values, not silently summed repeated observations. Repeated long-form heatmap cells similarly require explicit aggregation.

The user's reference image is a *style example*, not a source of experimental data or permission to recreate its curves. "Origin-like" here describes the requested framed axes, typographic balance, breathing room, grid hierarchy and distinct plotted series, not a claim to reproduce a specific OriginLab graph template. If journal instructions conflict, apply them only to the requested figure and state what differs from this default.

## Native CFD comparisons

- `xscale` and `yscale`: `linear` by default; `log` for positive numeric line/point-line/scatter/mixed input. Reject nonpositive values before plotting or export; no filtering or clipping of source values. These options do not change bar/violin categorical or heatmap matrix semantics (nonlinear scales are refused for those kinds).
- `series_styles`: mapping from stringified group label to an object with optional `color`, `linestyle`, `marker`, `line_width` (pt), `marker_size` (diameter, pt). Numeric group `180` is keyed as `"180"`; an ungrouped series is keyed as `""`. Unknown or ambiguous labels and unknown style keys raise errors. A per-series `kind` may repeat the native kind but cannot override it unless the whole plot is explicitly `mixed`. Mixed requires `kind` for **every** series. Line rejects markers; scatter rejects connecting styles; point-line requires both visible line and marker. Custom JSON dash patterns use `[offset, [on, off, ...]]`.
- Stroke sizing measures each connected series' own consecutive, in-frame points in **final transformed display coordinates**, after log scaling and outside-legend layout. Distances are normalized to the template's 120-dpi working canvas so changing export dpi does not alter the physical style. Thresholds remain 4/12/26 working pixels. Never pool density across connected series; do not sort or skip markers. The existing white sparse marker / filled close marker convention is unchanged. Scatter keeps the separate nearest-neighbor convention, now evaluated per series, with 5.5/4.5 pt diameters and existing dense alpha 0.85. Only the density diagnostic is sampled (up to 800 scatter positions), never the plotted data. Pure scatter sits above connecting lines in mixed plots.
- Size priority: per-series explicit size, then applicable global explicit size, then automatic. Marker shape, line style and color stay fixed. Legend handles and error artists copy the **resolved main-plot** size/fill/dash identity, even if the error panel has different apparent density.
- `error={"reference": "Theory", "definition": "signed"}` adds a shared-x, **linear-y** lower panel within the same physical size preset, without adding a fit, smoothing, uncertainty or a reference-zero curve. `signed = y-reference`, `absolute = abs(y-reference)`, `relative = (y-reference)/abs(reference)`; relative is a fraction, **not percent**. The reference is shown only in the main plot, comparisons in both panels. Signed/absolute error has the input y units; set `error["ylabel"]` (CLI `--error-ylabel`) when units need spelling out.
- Grid policy defaults to `interpolation="none"`: require exactly equal coordinate arrays in the same order. Equal row counts or nearly equal floats are not proof of matching grids. Explicit `interpolation="linear"` evaluates the reference in original **data** coordinates, not log space, at each comparison position in its original order. Require strictly increasing unique reference coordinates only when interpolation is actually needed; never sort them or extrapolate. Matching nonmonotonic coordinate arrays may be subtracted directly without reordering.
- Relative zero policy is `zero_reference="raise"`, the only implemented policy: if a reference evaluated at a comparison coordinate is zero, fail clearly before export. Select signed/absolute error or explicitly supply a scientifically justified nonzero domain; do not add epsilon, mask zeros or silently omit rows.
- API metadata: `figure.scientific_error_axes` gives the lower Axes (or `None`); `figure.scientific_metadata` records scales, resolved sizes, reference, formula, zero policy, and per-series exact/interpolation method plus error coordinates/values. An exported error comparison also writes `<basename>_metadata.json`; the returned `paths` remain image paths only. The CLI pins the JSON series config alongside its usual template and launcher. The complete CFD validation bundle additionally pins CSVs and parameters for relocatable offline replay.
